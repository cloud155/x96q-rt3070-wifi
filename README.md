# RT3070 Wi-Fi для ImmortalWrt на X96Q (ядро 6.12.85, sunxi/cortexa53)

Готовые драйверы и прошивка, чтобы USB Wi-Fi адаптер на чипе **Ralink RT3070**
(USB ID `148f:3070`, напр. Alfa) заработал на TV-боксе **X96Q** под
**ImmortalWrt 25.12-SNAPSHOT**, где Wi-Fi-стек изначально не установлен, а
интернета на самой коробке нет.

Всё собрано **строго под конкретное ядро** и проверено на живом устройстве:
адаптер определяется, поднимается `phy0`, прошивка `rt2870.bin` грузится.

## Для какой прошивки

| Параметр | Значение |
|---|---|
| Устройство | X96Q TV-Box (Allwinner, target `sunxi/cortexa53`) |
| Прошивка | ImmortalWrt `25.12-SNAPSHOT r0+37823-bce0a385ed` |
| Ядро | `6.12.85` |
| vermagic | `6.12.85 SMP mod_unload aarch64` |
| Коммит исходников | `bce0a385ed95e93bc86bd6ff3e5ec5fb25293454` |
| Адаптер | RT3070, `148f:3070` (RT chipset 3070 rev 0201, RF 0005) |

> ⚠️ **Модули ядра привязаны к версии ядра.** Они загрузятся только на ядре
> `6.12.85` с такой же строкой vermagic. На другом ядре — пересоберите
> (см. [«Пересборка»](#пересборка-под-другое-ядро)).

## Почему нельзя просто `apk add kmod-rt2800-usb`

1. **У коробки нет интернета** — WAN не поднят, DNS недоступен, штатный `apk`
   ничего не скачает.
2. **Прошивка на «протухшем» снапшоте.** Ядро `6.12.85` — это промежуточный
   снапшот; репозиторий ImmortalWrt уже уехал на `6.12.103`. Старые kmod'ы
   снапшота не архивируются, поэтому подходящих готовых пакетов в сети **нет**.
3. **`apk` требует точного совпадения хэша ядра.** Пакеты `kmod-*` зависят от
   `kernel=<версия>~<хэш-конфига>`. У этой (кастомной) прошивки хэш
   `f3e88af…`, а у любой пересборки он другой, поэтому `apk` отказывается
   ставить kmod'ы. Но само **ядро при загрузке модуля проверяет только строку
   `vermagic`**, а она совпадает — поэтому модули ставятся вручную (`.ko`), и это
   работает. Крипто-алгоритмы для WPA2/WPA3 (`ccm/gcm/cmac`) в ядре коробки уже
   вшиты, отдельные модули не нужны.

## Содержимое

```
modules/                 модули ядра (.ko), vermagic 6.12.85 SMP mod_unload aarch64
  compat.ko  cfg80211.ko  mac80211.ko  eeprom_93cx6.ko
  rt2x00lib.ko  rt2x00usb.ko  rt2800lib.ko  rt2800usb.ko
packages/                userspace-пакеты (не зависят от версии ядра)
  rt2800-usb-firmware-*.apk   (прошивка rt2870.bin)
  wireless-regdb-*.apk        (регуляторная БД)
  iw-*.apk                    (утилита iw)
etc/modules.d/50-rt2800usb-wifi   автозагрузка модулей при старте
examples/                примеры /etc/config/wireless (AP и STA)
build/build.sh           воспроизводимая сборка из исходников
install.sh  uninstall.sh установка/удаление
SHA256SUMS               контрольные суммы бинарников
```
## Быстрая установка

С компьютера, у которого есть доступ к коробке по SSH (пароль root по умолчанию `root`):

```sh
# 1) залить папку на приставку
scp -r x96q-rt3070-wifi root@192.168.4.1:/tmp/

# 2) запустить установщик на приставке
ssh root@192.168.4.1 "sh /tmp/x96q-rt3070-wifi/install.sh"
```

Если на ПК только PuTTY (Windows), то `pscp -scp ...` и `plink ...` соответственно.

`install.sh` сам: проверит версию ядра, скопирует `.ko` в `/lib/modules/6.12.85/`,
поставит прошивку/`iw`/`wireless-regdb` через `apk`, пропишет автозагрузку и
загрузит модуль `rt2800usb`.

## Проверка

```sh
# адаптер виден на USB?
for d in /sys/bus/usb/devices/*/idVendor; do cat "$d"; echo; done | grep -q 148f && echo "адаптер найден"

# радиоинтерфейс создан?
ls /sys/class/ieee80211/          # ожидаем phy0
iw phy0 info | head

# что в логах
dmesg | grep -iE 'rt2800|phy0|firmware'
# должно быть: RT chipset 3070 ... / Loading firmware file 'rt2870.bin' / Firmware detected
```

## Настройка Wi-Fi

Драйвер только даёт `phy0`; сеть настраивается в `/etc/config/wireless`.
Готовый блок для вашего адаптера печатает команда `wifi config`. Либо возьмите
шаблон из `examples/`:

- **Точка доступа (AP)** — коробка раздаёт Wi-Fi: `examples/wireless-ap.example`
- **Клиент (STA)** — коробка подключается к чужой сети: `examples/wireless-sta.example`

```sh
cp examples/wireless-ap.example /etc/config/wireless   # отредактируйте ssid/key
wifi up
wifi status
```

> `option path` в примерах соответствует USB-порту, где адаптер был при
> настройке (`3-1`). В другом порту path другой — сверьтесь с `wifi config`
> или используйте `option macaddr` (не зависит от порта). Подробности — в
> комментариях внутри файлов `examples/`.

## Автозагрузка

Файл `etc/modules.d/50-rt2800usb-wifi` (ставится установщиком в
`/etc/modules.d/`) заставляет `kmodloader` поднимать стек модулей при каждой
загрузке. `depmod` на этой сборке отсутствует, но это не мешает: `modprobe`
читает зависимости прямо из `.ko`.

## Пересборка под другое ядро

Если обновите прошивку и ядро изменится — модули нужно пересобрать под новый
vermagic. Скрипт делает всё сам на x86_64 Linux (проверено на Debian/Kali):

```sh
# COMMIT — полный SHA коммита вашей прошивки (см. «Firmware Version» в LuCI:
#   ...-<короткий_sha> ; полный SHA возьмите на github.com/immortalwrt/immortalwrt)
COMMIT=<полный_sha> ./build/build.sh
# результат в ./artifacts/{modules,packages}
```

Скрипт делает shallow-clone ImmortalWrt на нужном коммите, конфигурирует target
`sunxi/cortexa53`, собирает toolchain + ядро + `package/kernel/mac80211` и
кладёт `.ko` и `.apk` в `artifacts/`. Для другого устройства поменяйте target.

## Известные нюансы

- **Питание USB.** RT3070 прожорлив, а порты TV-бокса слабые. Если адаптер
  периодически отваливается с шины — используйте **USB-хаб с внешним питанием**.
- **Диапазон.** RT3070 — только 2.4 ГГц (802.11 b/g/n). 5 ГГц нет.
- **`option path` зависит от порта** (см. выше).
- **Только ядро 6.12.85.** Проверка версии встроена в `install.sh`.

## Технические детали

- Wi-Fi-стек: backports **mac80211 6.18.26** из core-дерева ImmortalWrt.
- Драйвер: `rt2800usb` → `rt2800lib` → `rt2x00lib`/`rt2x00usb` → `mac80211` →
  `cfg80211` (+ `compat`), EEPROM через `eeprom_93cx6`, CRC через встроенный
  `crc-ccitt` (уже есть в прошивке).
- Прошивка: `rt2870.bin` (version 0.36) из пакета `rt2800-usb-firmware`.
